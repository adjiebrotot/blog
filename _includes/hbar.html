{%- comment -%} A horizontal bar chart that compares countries, with one country highlighted. Usage in a post: {% include hbar.html id="gsl-informal" %} The data lives in _data/charts.json under that id (title, sub, source and each row's label and value text per language, plus the bar width in percent and the row's group: hl = the highlighted country, asean, oecd, avg, or na for "no data"). Country names come from _data/countries.yml. Colours follow the theme (blog.css, .hbar). {%- endcomment -%} {%- assign _c = site.data.charts[include.id] -%} {%- assign _l = page.lang | default: site.default_lang -%} {%- assign _t = site.data.i18n[_l] -%}
