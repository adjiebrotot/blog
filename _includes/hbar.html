{%- comment -%} A horizontal bar chart that compares countries, with one country highlighted. Usage in a post: {% include hbar.html id="gsl-informal" %} The data lives in _data/charts.json under that id (title, sub, source and each row's label and value text per language, plus the bar width in percent and the row's group: hl = the highlighted country, asean, oecd, avg, or na for "no data"). Country names come from _data/countries.yml. Colours follow the theme (blog.css, .hbar, the --pi-* tokens). Each row shows its country's flag (assets/img/flags/.svg, by the row's ISO alpha-3 code `c`, when _data/countries.yml knows it); a row whose code is not a country (OECD, x) or that sets "flag": false gets an empty slot so the names stay aligned, and "flag": "EUU" picks another flag. A chart sets "flags": false to show none. Part of the procedural-illustration skill's design system. {%- endcomment -%} {%- assign _c = site.data.charts[include.id] -%} {%- assign _l = page.lang | default: site.default_lang -%} {%- assign _t = site.data.i18n[_l] -%}
