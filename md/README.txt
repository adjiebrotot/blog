Each file here publishes one post as Markdown at <post URL>index.md, for AI readers
(llms.txt-style). The text comes from the post itself, so a stub never goes stale. For a
new post, copy a stub, name it <lang>-<slug>.txt and set its permalink and md_of to the
post's URL. A post without a stub simply has no Markdown copy and no link to one.
